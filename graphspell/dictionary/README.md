# Dictionary engine and native generator

This package implements Grammalecte's compact acyclic word graph in Go, including
modern integer-array JSON and the legacy hexadecimal encoding. Dictionaries are
validated before use and are immutable, allowing concurrent queries.

The embedded default dictionary contains 515,637 distinct entries from 515,693
rows in the original French lexicon. The source includes 56 duplicate rows.
No data files, interpreter or network access are required at runtime. The full
source lexicon is also compressed into the executable, so `BuildBundled` can
regenerate the graph natively without a separate checkout. Classic and 1990
reform variants are generated once in memory from that same source.

## APIs

- `Default`, `Bundled`: cached embedded dictionaries.
- `BuildBundled`, `Build`: native deterministic graph generation.
- `BundledLexicon`, `ReadLexicon`: source lexicon access and TSV parsing.
- `Read`, `Load`, `Write`: portable graph serialization.
- `Lookup`, `Morph`, `MorphExact`, `Stem`: exact and normalized lexical queries.
- `IsValid`, `IsValidToken`, `WithAcronyms`: upstream casing and compound rules.
- `Entries`, `Select`: ordered lexical enumeration with standard-library filters.
- `Suggest`, `SuggestContext`, `SimilarEntries`: spelling suggestion generation,
  ranking, morphology expansion and optional cancellation.

Text must be valid UTF-8. `Morph` preserves Python's normalization and case
expansion; `MorphExact` is appropriate when comparing raw lexical source rows.
Some source rows intentionally use spellings changed by normalization, so an
exhaustive source test must not substitute `Morph` for `MorphExact`.

The generated arc order, affix code assignment and frequency ordering follow
the original generator. Wall-clock dates are never inserted implicitly: callers
may explicitly set a metadata date. `Stats.Tags` retains the upstream `nTag`
convention, which includes the reserved value slot.

The suggestion search retains the upstream two passes, weighted distances,
phonetic replacements, adaptive limits and lexicographic score tie-breaks. The
reference's tail enumeration uses a Python hash set; this implementation sorts
that set for deterministic execution. The fixture's complete ordered outputs
match the recorded Python run, but this does not assert equivalence to every
possible Python hash seed for every input.

Standard-library regexes handle dictionary filters and the finite French
prefix/suffix patterns. Unsupported filter syntax returns an error. This API
does not silently translate arbitrary Python regex syntax.

## Evidence

`testdata/dictionaries.json` contains three dictionaries generated by the pinned
Python implementation, covering all three stemming modes, and 111 lookup,
validation and morphology query cases. Tests compare both results and the exact
serialized value/arc arrays produced by the native builder. The suite also
covers legacy decoding, invalid/cyclic graph rejection, deterministic generation,
all source lexical rows, embedded source checksums, complete graph regeneration,
spelling variants, cancellation, I/O errors and 55 ordered suggestion cases.

The Python suggestion fixture loads the native full graph through Python's
`IBDAWG`, providing an independent check of binary-format interoperability. Its
French lexicographer module is enabled. Normal tests read frozen JSON and do not
execute Python. `data/provenance.json` pins the upstream revision and source hash.
